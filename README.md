A fast, zero-dependency, single-page developer portfolio deployed via GitHub Pages. Built with semantic HTML5, modern CSS (featuring glassmorphism and ambient mesh glow animations), and native IntersectionObserver scroll effects.

## 🚀 Key Highlights & Stack

- **Role:** Software Developer & AI Engineer
- **Core Languages:** Python, C#, JavaScript, SQL, HTML5/CSS3
- **Frameworks & Libs:** .NET / ASP.NET MVC, React.js, Django, Flask, Streamlit
